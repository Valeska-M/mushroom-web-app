# Responsive web app for mushroom identification
The website I am revamping, [original page](https://123pilzsuche.de/) is well known and widely used among mushroom hunters to identify and find out more about species. Therefore I am working on a responsive and modernized version that improves the clarity and usability. In addition to the programming, I revised the structure of the pages, standardized all graphics and designed a new text logo. 
Check out my current version of the page: [new page](https://valeska-m.github.io/mushroom-web-app/)

## Tech Stack
HTML, CSS, Vanilla JavaScript, Adobe InDesign

## Features
- Responsive layout for desktop and mobile devices
- Hybrid architecture combining static HTML pages with SPA-like functionality of the main page
- URL query parameters enable navigation and direct linking to individual mushroom profiles without requiring separate HTML files
- Scroll-based animations
- Dynamic rendering of mushroom data (search results and mushroom profiles), currently from a JSON file

## Project Status
This web app is a work in progress. The frontend of the main pages is finished for now, my main focus was on the search page with the filter popup and the profile pages for the different mushrooms. I am currently waiting for more information about the existing database to start with the backend and implement the search functionality.
